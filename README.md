# Lamosa Studio — Next.js & Tailwind CSS Clone

A pixel-perfect clone of the [Lamosa Framer Website Template](https://whole-play-681827.framer.app/) built with **Next.js (App Router)**, **Tailwind CSS**, and **TypeScript**.

## Quick Start

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

## Production Build

```bash
# Build static & optimized production bundle
npm run build

# Run production server
npm run start
```

## Features Included

- **Home Page (`/`)**: Hero with pulse badges, floating social proof ticker, client logo marquee, impact stats, service capabilities, projects showcase, 4-step process, wall of love reviews, pricing matrix, FAQ accordion, blog preview, and conversion CTA.
- **Projects Archive (`/projects`)**: Filterable project gallery by category.
- **Case Study Detail Pages (`/projects/[slug]`)**: 6 detailed project case studies with challenge, solution, and results.
- **Blog Archive (`/blog`)**: Category-filtered insights and articles.
- **Article Detail Pages (`/blog/[slug]`)**: Full articles with reading time and author bios.
- **Contact Us (`/contact-us`)**: Working inquiry form and discovery call booking prompt.
- **Legal Documentation**: Privacy Policy and Terms of Service.
